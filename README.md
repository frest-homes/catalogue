# catalogue.fresthomes.com

English edition of the Frest price catalogue for first leads. Prices for the Irish and EU market excluding VAT, from the pricing parameters in Lab (frest-pricing). Assembly is included; transport, foundations, connections and VAT are quoted per project and the page says so. Pages are AES-GCM encrypted at build time; the browser decrypts with the catalogue code (PBKDF2-SHA256 300k). Codes are shared with the sister edition and rotate monthly (`catalogue/data/codes.json`, two valid at a time). The gate opens with a market chooser: a visitor who picks a market this domain does not serve is handed to catalogue.frest.lv with `?m=<code>`. Request form → FormSubmit → auto-reply with the current code. No server, no accounts. Generator in Drive `WEB/gates/`.
